# Signalbox Sync

Signalbox Sync is the Obsidian plugin that keeps your vault in [Signalbox](https://signalbox.run), so your agents can read, search and edit your notes while your devices are off.

## Install

Open **Connect Obsidian** in Signalbox and follow its two steps. It adds this plugin through [BRAT](https://github.com/TfTHacker/obsidian42-brat), which keeps it up to date every time Obsidian starts.

To add it by hand instead, install BRAT, choose **Add beta plugin**, enter `JustYannicc/signalbox-sync` and pick **Latest version**.

## Releases

Each release is tagged with its version (for example `0.2.3`) and carries `main.js`, `manifest.json` and `styles.css`. Published versions never change.

The plugin is developed in the [Basalt](https://github.com/JustYannicc/basalt) repository, under `clients/obsidian`, and every release here is built from it. Report problems there.
